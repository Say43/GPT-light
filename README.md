# GPT-light

A lightweight experimental LLM project focused on building and testing small chatbot workflows.

This repository combines:
- a token-based mini GPT/Transformer training path inspired by Karpathy
- a Colab-based workflow for rapid experimentation
- practical fine-tuning and chat-oriented prototyping
- lightweight chatbot inference experiments with small open models such as Phi-3 Mini

The goal is to explore how far small-scale language model training, fine-tuning, and chatbot behavior can be pushed on limited hardware such as Google Colab T4.
